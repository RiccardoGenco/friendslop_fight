# friendslop_fight

Platform fighter laterale 2D su schermo condiviso, 2-6 giocatori, fatto con [LÖVE](https://love2d.org) 11.5.

**Per giocare su Windows:** scarica la repo (Code → Download ZIP) e fai doppio clic su `GIOCA.bat`. LÖVE è già incluso.
Su altri sistemi: installa LÖVE 11.5 e lancia `love gioco`.

Il codice del gioco sta in [`gioco/`](gioco/), con comandi e dettagli nel [README del gioco](gioco/README.md).
I file `love.exe`, le DLL, `license.txt`, `readme.txt` e `changes.txt` sono il runtime di LÖVE (licenza zlib).
